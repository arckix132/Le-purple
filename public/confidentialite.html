LE PURPLE · CONFIDENTIALITÉ

Vos données, simplement.

Le Purple est un jeu de cartes à partager. Vous pouvez jouer sans compte. Si vous créez un compte, nous enregistrons votre prénom et votre adresse e-mail pour retrouver votre identité dans le jeu. Un mot de passe est conservé uniquement sous forme d’empreinte dérivée ; la session est maintenue par un cookie sécurisé pendant 30 jours.

Si vous choisissez « Continuer avec Google », nous utilisons l’identifiant de votre compte Google, votre adresse e-mail et votre nom fournis lors de la connexion. Le Purple n’accède pas à vos contacts, à votre Drive ni à vos messages. Ces données servent uniquement à créer ou retrouver votre compte Le Purple.

Les salons en ligne conservent les prénoms, scores, pénalités choisies et actions de la partie pour synchroniser les joueurs. Un salon devient inaccessible 24 heures après sa création. Une partie locale est sauvegardée uniquement dans le navigateur de votre appareil ; vous pouvez effacer cette sauvegarde depuis les données du navigateur.

Si vous utilisez les amis, nous conservons votre code ami, les demandes, les liens d’amitié et les invitations à jouer. Un ajout doit être accepté par le destinataire. Votre prénom, votre code ami et votre activité récente dans Le Purple sont visibles par vos amis ; votre adresse e-mail ne leur est pas communiquée. Le statut en ligne s’arrête après 90 secondes sans activité dans l’application. Les invitations deviennent indisponibles après 15 minutes ou la fermeture du salon. Vous pouvez annuler une demande ou retirer un ami depuis la liste Amis ; ce retrait supprime les invitations entre vos deux comptes.

Les données de compte et de salon sont hébergées par les services techniques utilisés par Le Purple. Nous ne vendons pas les données des joueurs. Pour demander l’accès ou la suppression de votre compte, écrivez à loislemesle@gmail.com.
